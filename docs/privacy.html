プライバシーポリシー - Ambient Light for 動画配信

最終更新日: 2026年10月10日

「Ambient Light for 動画配信」（以下「本拡張機能」）は、TVer・ABEMA・ニコニコ動画などの動画再生画面に 映像の色をもとにしたアンビエントライト効果を追加する非公式のChrome拡張機能です。 本ポリシーは、本拡張機能が取り扱う情報について説明します。

収集する情報

本拡張機能は、氏名・メールアドレス・閲覧履歴・位置情報などの個人を特定できる情報を一切収集しません。 外部サーバーへの通信や、第三者への情報提供も行いません。

保存する情報

本拡張機能の「有効/無効」「強さ」「なめらかさ(FPS)」といった設定値のみを、Chromeが提供する chrome.storage.sync API を用いて保存します。このデータはユーザーご自身のGoogleアカウントに 同期される場合がありますが、開発者を含む第三者がアクセスすることはありません。

動画コンテンツの取り扱い

本拡張機能は対応サイトの動画再生画面上で映像フレームを読み取り、色情報の抽出のみをブラウザ内（ローカル）で行います。 映像データの保存・送信・録画は一切行いません。

権限について

本拡張機能が要求する権限は storage（設定の保存）と、対応サイト（TVer・ABEMA・ニコニコ動画）の ページ上でのみ動作するための host_permissions のみです。

お問い合わせ

本ポリシーに関するご質問は、GitHubリポジトリのIssueよりご連絡ください。

本拡張機能は非公式のファンメイドツールであり、TVer・ABEMA・ニコニコ動画および関係各社とは一切関係ありません。
